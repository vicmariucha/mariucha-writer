# Writer Portfolio & Editorial Blog

A modern, intuitive, and professional writing portfolio and digital magazine designed for a science writer and developer. It blends clean editorial aesthetics with high-performance functionality, bridging the gap between technical expertise and compelling storytelling.

## Overview

This project serves as a sophisticated personal brand hub and publishing platform. It features an editorial layout reminiscent of high-end digital publications, optimized for reading experiences, content categorization, and professional outreach.

## Core Features & Pages

- **Sticky Minimalist Header**: Refined typography featuring a personalized logo, smooth navigation links ("About", "Articles", "Contact"), and a distinct "Hire Me" call-to-action button.
- **Landing Page (Home)**: 
  - An impactful Hero section focusing on translating complex science and technical topics into engaging stories.
  - A curated grid of featured articles equipped with smooth hover animations.
  - An introductory author preview highlighting cross-disciplinary expertise.
- **Articles Hub**: 
  - Clean masonry and grid-based layouts for content consumption.
  - Interactive category tags (e.g., #Biotech, #Climate, #Space, #Neuroscience, #Health) for streamlined filtering.
  - Real-time keyword search bar, estimated read times, and publication timestamps.
- **About Me Section**: 
  - A high-end editorial bio detailing academic background, professional experience in science communication, and technical skills.
  - Dedicated credentials and resume/CV download integration.
- **Contact & Collaboration Hub**: 
  - A clean, minimalist contact form with interactive success states.
  - Direct professional email display and structured links to professional networks (LinkedIn, GitHub, Substack).
- **Secure Administrative Dashboard**: 
  - A protected backend area restricted to site owners, allowing content and interaction management through secure authentication and custom role validation.

## Technical Architecture & Stack

- **Frontend & Routing**: React powered by TanStack Start for high-performance server-side rendering and client-side transitions.
- **Styling**: Tailwind CSS for responsive, mobile-first design, featuring custom typography and sophisticated neutral color palettes.
- **Backend & Database**: Supabase (PostgreSQL) handling user authentication, secure row-level security (RLS) policies, administrative roles, and database functions (RPCs).
