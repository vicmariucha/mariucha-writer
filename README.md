# writer-portfolio

Create a modern, intuitive, professional yet youthful writing portfolio website for a science writer, entirely in English. The aesthetic must be high-end, chic, elegant, and unique, blending clean editorial design (resembling a sophisticated digital magazine) with high-performance functionality.

Here is the structure and requirements for the app:

1. Navigation Bar (Header):

- Minimalist and sticky.

- Logo/Name on the left with a refined typography style.

- Clean navigation links on the right: "About", "Articles", "Contact", and a subtle "Hire Me" button with a sleek hover effect.

- Dark mode toggle or a sophisticated neutral color palette (e.g., deep charcoal, warm cream/off-white background, and an accent color like muted sage green or deep terracotta for a modern scientific feel).

2. Home / Landing Page:

- Hero Section: A bold, elegant headline introducing the writer (e.g., "Translating complex science into compelling stories"), a short punchy subheadline, and direct calls to action ("Read Articles" and "Get in Touch").

- Featured Articles Section: A curated grid showcasing top/recent pieces with smooth hover card animations.

- Brief About Preview: A short intro statement highlighting expertise in science communication, journalism, and storytelling.

3. Articles Page (The Core):

- Layout: A clean list or masonry grid of articles.

- Tag System: Interactive filter tags at the top (e.g., #Biotech, #Climate, #Space, #Neuroscience, #Health) so visitors can easily filter content by category.

- Article Card Elements: Each card must display the article title, a concise excerpt, publication date, read time (e.g., "4 min read"), category tag, and an external link or a clean dedicated reading view.

- Search bar to quickly find articles by keyword.

4. About Me Page:

- A sophisticated editorial layout with a professional author photo placeholder.

- Compelling bio focusing on scientific background, passion for science communication, and areas of expertise.

- Credentials/Trust bar or section: Logos or mentions of publications, academic background, or awards.

- Download CV/Resume button with a clean icon.

5. Contact Page:

- Minimalist, elegant contact form with fields for Name, Email, Subject, and Message, plus a success state animation.

- Direct professional email display and social/professional links (LinkedIn, Twitter/X, Substack, GitHub or ORCID if applicable).

- A polite note welcoming freelance inquiries, collaborations, and pitches.

6. Design & Technical Guidelines:

- Styling: Use Tailwind CSS with clean typography (e.g., serif headings like Playfair Display or Inter combined with a clean sans-serif body font). Generous whitespace, subtle borders, and smooth transitions.

- Fully responsive (mobile-first, flawless tablet and desktop views).

- Delightful micro-interactions (e.g., smooth fading, subtle shadow elevations on hover).
